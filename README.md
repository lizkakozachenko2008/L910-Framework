# L910 Framework

Учебный проект: минималистичный HTTP‑фреймворк на Node.js (без Express) и несколько REST API модулей (авто, спортзал, доставка еды, армия).

## Требования

- Node.js 18+
- npm

## Установка и запуск

npm install
npm start

Сервер запустится на `http://localhost:3000`.
